
# 🖥️ OS LAB — Laboratorio Interactivo de Sistemas Operativos

**OS LAB** es una plataforma web educativa desarrollada con ReactJS que tiene como objetivo facilitar el aprendizaje de los conceptos fundamentales de los Sistemas Operativos mediante simulaciones, visualizaciones interactivas y experimentación práctica con código.

El proyecto busca conectar la teoría con la práctica, permitiendo que los estudiantes comprendan cómo funcionan internamente los sistemas operativos a través de laboratorios virtuales.

> Aprende. Ejecuta. Experimenta.

---

## 🎯 Objetivos del proyecto

- Comprender los fundamentos y conceptos de los Sistemas Operativos.
- Representar visualmente los mecanismos internos de un sistema operativo.
- Experimentar con algoritmos y técnicas utilizadas en la gestión de recursos.
- Implementar simulaciones interactivas de los diferentes temas.
- Practicar mediante ejemplos de código y ejercicios.
- Relacionar los conceptos teóricos con situaciones prácticas.

---

## 🚀 Funcionalidades principales

- **Dashboard:** panel principal con acceso a los diferentes temas y seguimiento del aprendizaje.
- **Laboratorios interactivos:** simulaciones para experimentar con los conceptos de Sistemas Operativos.
- **Visualizaciones:** diagramas, animaciones y representaciones gráficas de los algoritmos.

---

## 📚 Contenido del proyecto

La plataforma estará organizada en cinco grandes bloques temáticos: mismos que tendran un simulador por tema

### 1. Introducción

- Definiciones.
- Tipos de sistemas operativos.
- Historia de los sistemas operativos.

### 2. Organización

- Componentes de un sistema operativo.
- Servicios del sistema operativo.
- Interfaz de programación.
- Operación del sistema operativo.
- Sistemas operativos por su estructura.

### 3. Gestión de procesos

- Procesos.
- Planificación de la CPU.
- Paso de mensajes.
- Memoria compartida.
- Hilos.
- Sincronización.

### 4. Gestión de la memoria

- Memoria principal.
- Paginación.
- Memoria virtual.

### 5. Gestión del almacenamiento

- Almacenamiento secundario.
- Sistemas de archivos.
- Implementación de sistemas de archivos.

## ⚙️ Instalación y ejecución

### Requisitos previos

- Node.js
- npm
- Git

### 1. Clonar el repositorio

```bash
git clone https://github.com/TU-USUARIO/os-lab.git
```

### 2. Acceder al proyecto

```bash
cd os-lab
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar el servidor de desarrollo

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:5173/
```
